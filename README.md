# ISP DOB Validation

Hardware validation page for a disturbance observer (DOB) on a single-axis inertially stabilized platform: tracked rig videos, logged signals and a 3D replay, observer off against on.

Live page: https://coolab-inu.github.io/isp-dob/

The page is static. `index.html` loads the two logged runs (`data.js`), per-frame video tracking of the two clips (`track.js`), the CAD model (`model.js`, the same bytes as `media/isp.glb`) and the clips and posters in `media/`.
